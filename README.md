# Arch 04 — Diffusion Language Models

A deep technical dive into non-autoregressive language generation via diffusion: the case for parallel decoding, score-based discrete diffusion (SEDD) with absorbing-state and uniform-noise schedules, LLaDA's large-scale masked diffusion approach, mask-prediction scheduling strategies, the inference compute trade-off against autoregressive models, benchmark quality gaps and where they close, structured-output and code generation advantages, and open research questions in the field.
