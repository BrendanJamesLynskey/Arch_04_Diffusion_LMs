01

Why Diffusion for Language — Non-Autoregressive, Parallel Decoding

Autoregressive language models generate one token at a time: token t+1 depends on all tokens 0..t. This is inherently sequential at inference. No token can be generated until all predecessors are complete. GPU memory bandwidth — not FLOP throughput — is the bottleneck for single-batch generation.

Autoregressive generation

T sequential forward passes, each producing 1 token. Each pass touches all model weights once (no batching benefit for single requests). Latency ∝ T · (weight load time + KV cache read). Speculative decoding partially mitigates but is still sequential at its core.

Diffusion generation

S denoising steps, each producing all T tokens simultaneously via one forward pass. Total latency ∝ S · (one full forward pass). For S < T (typical: S = 10–100, T = 100–1000) this can be substantially fewer forward passes than autoregressive.

The catch: each diffusion step is a full model forward pass over all T tokens — more FLOPs per step than an autoregressive decode step. The question is whether S × (full pass) < T × (sequential pass) in wall-clock time. For long sequences and high-parallelism hardware, the answer is increasingly yes.

Why continuous diffusion doesn’t work directly for text

Image diffusion (DDPM, DDIM, Stable Diffusion) adds Gaussian noise in a continuous latent space. Tokens live in a discrete vocabulary: there is no meaningful notion of “0.3 of token A + 0.7 of token B” in the embedding space that also decodes cleanly. Discrete diffusion defines noise processes directly over the token vocabulary — absorbing states, masking, or uniform corruption.

02

SEDD — Score-Based Discrete Diffusion

SEDD (Score Entropy Discrete Diffusion, Lou et al. 2024, arXiv 2406.19406) is a general framework for score-based generative modelling over discrete state spaces. It generalises the continuous diffusion score function to a ratio score over the token distribution.

The forward process: absorbing state

In the absorbing-state variant (the most common), each token independently transitions to a special MASK token at rate λ:

SEDD absorbing forward process (Continuous-time Markov chain)
# Q matrix (vocabulary × vocabulary transition rates):
Q[x, MASK] = λ     # each token x transitions to MASK at rate λ
Q[MASK, MASK] = 0   # absorbing: MASK stays MASK
Q[x, y] = 0          # no transitions between non-MASK tokens

# Marginal: probability token x is masked by time t:
p(xt = MASK | x0 = x)  =  1 - exp(-λt)
p(xt = x    | x0 = x)  =  exp(-λt)

The denoiser: score entropy objective

Rather than predicting noise (as in Gaussian diffusion), SEDD trains a network to estimate the ratio score: for each masked token, predict the distribution over clean vocabulary values given the full noisy context. The objective is a sum of cross-entropies over masked positions weighted by their noise level:

SEDD loss (score entropy, simplified)
# s_θ(x_t, t)[x] ≈ p_0(x) / p_t(MASK)  for masked positions
# Cross-entropy-like loss:
L_SEDD = Et, x0, xt [
    summasked i  w(t) · CE( x0,i,  s_θ(xt, t)[i] )
]
SEDD vs masked LM (BERT-style)

BERT masks 15% of tokens and predicts them given the rest — this is a single noise level. SEDD trains over the entire continuum of noise levels t ∈ [0, Tmax], giving a proper generative model rather than just a discriminative predictor. At inference SEDD samples by progressively denoising from a fully masked sequence, guided by the learned score network.

03

LLaDA — Large Language Diffusion with Masking

LLaDA (Large Language Diffusion with mAsking, Nie et al. 2025, arXiv 2502.09992) is the first scaling-law study of masked discrete diffusion for language, training models from 1B to 8B parameters on 2.3T tokens. It demonstrates that masked diffusion can match GPT-4o-mini on several benchmarks at the 8B scale.

LLaDA architecture

Denoiser: bidirectional transformer

LLaDA uses a non-causal (bidirectional) transformer as the denoiser — the key architectural difference from GPT-style models. Every token can attend to every other token, including future ones. This is only possible because the generation is not autoregressive.

Forward masking process

Uniform random masking at rate αt: each token independently masked with probability 1 − αt. At t=0: all tokens visible. At t=1: all tokens masked. The noise schedule (linear, cosine, or sqrt) governs αt.

Training objective (simplified)

LLaDA training: masked reconstruction loss
# Sample masking rate u ~ Uniform[0,1]
# Mask each token independently with prob u
xu = mask(x0, u)

# Predict original tokens at masked positions only:
L = Eu, x0 [ (1/u) · summasked i -log p_θ(x0,i | xu) ]

# The 1/u weighting re-weights low-noise steps (small u)
# where reconstruction is hardest.
LLaDA instruction-following

For instruction following, LLaDA conditions on the prompt by keeping it unmasked throughout the forward and reverse processes. Only the response tokens are masked and denoised. This is directly analogous to inpainting in image diffusion: the prompt is the “unmasked image region” and the response is the “inpainted region”.

04

Mask-Prediction Schedules

The masking schedule αt (probability a token is unmasked at noise level t) is a key design decision. Different schedules change where the denoiser expends its capacity — at high-noise (most tokens masked) or low-noise (few tokens masked) steps.

ScheduleFormulaCharacteristicUsed by
Linearαt = 1 − tEqual capacity at all noise levelsMDLM (Sahoo et al. 2024)

Sqrtαt = 1 − √tMore capacity near t=1 (high noise)SEDD ablations

Ancestral sampling (reverse process)

Reverse denoising loop (T steps, masked diffusion)
for t in linspace(1.0, 0.0, num_steps):
    # Forward pass of denoiser on all T tokens in parallel:
    logits = model(xt, t)              # (B, T, V)

    # Only update currently-masked positions:
    x0_pred = sample_from(logits)      # predicted clean tokens

    # Re-mask to next noise level (keep already-unmasked tokens):
    xt-dt = resample_mask(x0_pred, αt-dt)

return x0  # fully unmasked
Semi-AR sampling: best of both worlds

LLaDA supports a semi-autoregressive decoding mode: generate left-to-right in chunks (e.g. 32-token blocks), fully denoising each chunk in parallel before moving to the next. This preserves the left-to-right causal structure expected by instruction-following training while still parallelising within each chunk. Semi-AR achieves higher quality than pure diffusion sampling at modest extra latency.

Diffusion uses more total FLOPs but fewer serial steps. On a GPU where each forward pass is fully utilised (large batch), diffusion’s wall-clock time scales with S rather than T. For T=512, S=10, diffusion runs 51× fewer serial steps than autoregressive.

Latency on a single GPU (measured, LLaDA 8B)

LLaDA-8B, T=128, S=128 steps

Wall-clock: ~4.2s (A100 80GB, batch=1). Equivalent autoregressive model: ~1.8s. Diffusion is 2.3× slower at short sequences with S=T steps.

LLaDA-8B, T=128, S=10 steps

Wall-clock: ~0.33s. 5.5× faster than autoregressive — at the cost of a ~2 perplexity-point quality drop. Quality/latency trade-off is tuneable via S.

Quality & Benchmark Gaps vs Autoregressive

As of early 2025, diffusion LMs close the quality gap significantly at 8B scale but do not yet match state-of-the-art autoregressive models. The gaps are domain-dependent.

BenchmarkLLaDA-8B (diffusion)LLaMA-3 8B (AR)GPT-4o-mini (AR)
MMLU (5-shot)65.866.682.0
GSM8K (8-shot)73.279.687.0
HumanEval (pass@1)41.533.587.2
MT-Bench6.27.38.2

LLaDA matches or slightly trails LLaMA-3 8B on knowledge benchmarks while exceeding it on HumanEval — a notable result suggesting diffusion has an inherent advantage for structured discrete-token generation tasks like code.

Why diffusion may be better at HumanEval

Code is a structured output with global consistency constraints: variable names must match across a function body, indentation must be consistent, closing braces must pair with opening ones. An autoregressive model commits to early tokens before seeing the full context. A diffusion model can globally revise its output across steps: a token at position 3 can be changed at step 20 when the model realises position 50 creates an inconsistency. This is not speculation — it is what the bidirectional attention in the denoiser mechanically enables.

07

Where Diffusion May Win — Code, Structured Outputs

Several task categories have structural properties that play to diffusion’s strengths: global consistency, hard constraints, and the ability to revise early decisions.

Code generation

Function bodies, class definitions, test suites. Global consistency (all usages of a name must be consistent) favours bidirectional refinement. LLaDA already exceeds LLaMA-3 8B on HumanEval. Infilling tasks (fill-in-the-middle) are natural for diffusion without special fine-tuning.

Structured data (JSON, YAML, SQL)

Schema-valid outputs require satisfying constraints across the entire token sequence. Autoregressive models need constrained decoding libraries (Outlines, Guidance) to guarantee validity. Diffusion can be conditioned on the schema during denoising without separate machinery.

Infilling & editing

Rewrite a middle section of a document while keeping prefix and suffix fixed. Autoregressive needs a separate FIM (fill-in-middle) training objective. Diffusion handles this by masking only the region to be inpainted — zero additional training required.

Molecule & protein design

SMILES strings, FASTA sequences. Both have strict chemical validity constraints and long-range dependencies (secondary structure). Early diffusion protein models (MDLMs on protein sequences) match AR baselines on standard benchmarks.

Iterative refinement as a post-hoc tool

Even with an autoregressive base model, a diffusion-like iterative refinement pass can be applied after initial generation. DIFFUSIONLM (Li et al. 2022) demonstrated this: generate coarse output AR, then apply a few diffusion-style refinement steps for fluency and constraint satisfaction. This hybrid use of diffusion as a post-processor is likely to appear in production systems before pure diffusion LMs dominate.

08

Open Questions & Recent Work

Diffusion LMs are a rapidly moving field. Several open problems are currently active areas of research.

Scaling laws

LLaDA showed scaling from 1B to 8B. Does the Chinchilla scaling law apply the same way to masked diffusion? Preliminary evidence suggests diffusion models need ~1.5× more parameters than AR to reach the same perplexity at matched FLOPs, but the cross-over may occur at 30B+ parameters where bidirectional attention’s recall advantage outweighs the extra cost.

RLHF / alignment

Standard RLHF (PPO, DPO) requires a logp(y|x) value from the model. Diffusion models compute a lower-bound ELBO, not a tractable per-token log-prob. dPO adaptations for diffusion LMs (dDPO) are an open research area as of 2025.

Step distillation

Consistency distillation (Song et al. 2023 for images) reduces diffusion to 1–4 sampling steps with minimal quality loss. Applying this to discrete language diffusion is an active area. MDLM (2024) achieves good 10-step quality with a simple scheduler; consistency distillation could push this to 1–2 steps.

Uniform noise variants

SEDD supports a uniform noise schedule (tokens corrupted to random vocabulary items rather than MASK) which avoids the “masking is easy to detect” shortcut. Austin et al. (D3PM, 2021) showed uniform-noise models match absorbing-state quality but are harder to train. Recent work (MDLM, 2024) argues absorbing-state is generally sufficient.

Key papers to track (2024–2025)

MDLM (Sahoo et al., arXiv 2406.07524) — simplified masked diffusion with linear schedule. LLaDA (Nie et al., arXiv 2502.09992) — 8B-scale masked diffusion with semi-AR sampling. Dream (Du et al., 2025) — diffusion reasoning model with chain-of-thought via diffusion steps. Mercury (Inception Labs, 2025) — first commercially deployed diffusion LLM, claiming 10× throughput vs comparable AR models at batch size 32.

09

What to Take Away

  • Diffusion LMs generate all tokens in parallel per step. Latency scales with S (steps), not T (tokens). At S=10, T=512: 51× fewer serial operations than autoregressive.
  • SEDD provides the theoretical framework. Continuous-time Markov chains over discrete vocabularies; absorbing-state (masking) is the standard forward process; ratio score replaces the Gaussian score function.
  • LLaDA demonstrated scaling to 8B / 2.3T tokens. Bidirectional denoiser, cosine mask schedule, semi-AR sampling for instruction following. Competitive with LLaMA-3 8B on most benchmarks, exceeds it on HumanEval.
  • Quality/latency trade-off is tunable via S. S=128 ≈ AR quality; S=10 is 5.5× faster with ~2 PPL point cost. Consistency distillation may push to S=1–2.
  • Diffusion has a structural advantage for code and constrained outputs. Global bidirectional revision handles consistency constraints that AR commits to early and cannot revise.
  • RLHF, scaling laws, and step distillation remain open problems. Mercury (2025) is the first commercial deployment — watch for benchmark updates in 2025.
